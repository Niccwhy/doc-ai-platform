# 技术选型

### 一、 前端技术
*   **React + TypeScript**：构建前端应用；强类型约束活文档的 JSON 树结构。

### 二、 后端技术
*   **Java + Spring Boot**：系统核心框架。
*   **Spring `@Async` 线程池**：执行耗时的文档解析、AI 抽取与生成等异步任务。
*   **SSE (Server-Sent Events)**：替代轮询，用于向后端实时推送任务进度。

### 三、 数据与存储
*   **PostgreSQL 16**：存储业务元数据、任务状态、结果及活文档 JSON。
*   **pgvector**：存储文档块向量，提供 RAG 语义检索。
*   **MinIO**：存储原始物理文件（源文件、模板、最终导出物）。
*   **Docker Compose**：管理 PG 和 MinIO 的本地依赖环境。

### 四、 AI 与文档引擎
*   **Apache Tika / POI**：解析多格式文档、提取模板占位符及数据回填。
*   **LLM API (大语言模型)**：解析自然语言指令、执行结构化抽取、生成 JSON 树或填表指令。
*   **Embedding API**：将文档块转化为向量。

### 五、 规范与测试
*   **AGENTS.md**：约束 AI 编码时的核心规则（如多租户隔离、软删除）。
*   **JUnit 5 + Mockito**：编写单元测试用例。
